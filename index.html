Antes de comenzar

Estos conceptos te ayudan a entender qué estás configurando y por qué cada dispositivo utiliza una IP de manera diferente.

01

Router

Conecta diferentes redes y dirige los paquetes de datos entre ellas. La IP normalmente se asigna directamente a una interfaz física.

02

Switch de capa 2

Permite conectar dispositivos dentro de una red. Para administrarlo mediante IP se utiliza una interfaz virtual asociada a una VLAN.

03

SVI

Significa Switch Virtual Interface. Es la interfaz virtual de una VLAN utilizada para asignar la IP de administración al switch.

04

CLI

La Command Line Interface permite introducir los comandos de configuración en equipos Cisco.

05

Gateway

Es la puerta de enlace que permite al switch utilizar el router para comunicarse con redes diferentes a la red local.

06

Packet Tracer

Entorno de práctica utilizado para simular y comprobar configuraciones de redes Cisco sin necesidad de equipos físicos.

⭐ Dato que debes recordar: en el router la IP se asigna normalmente a una interfaz física; en un switch de capa 2, la IP de administración se asigna a una interfaz virtual de VLAN.

1. Administración básica de un router

Configuraremos la interfaz FastEthernet0/0 con la dirección 192.168.10.1.

📌 Datos de la red

DatoValor
Red192.168.10.0/24
Máscara255.255.255.0
IP del router192.168.10.1
Interfaz utilizadaFastEthernet0/0
1

Entrar al modo privilegiado

Primero se utiliza enable.

Cisco CLI 
enable
2

Entrar a configuración global

Cisco CLI 
configure terminal
3

Seleccionar la interfaz

En este ejemplo se utiliza FastEthernet0/0. También puede escribirse como fa0/0.

Cisco CLI 
interface FastEthernet0/0
4

Asignar IP y activar la interfaz

Cisco CLI 
ip address 192.168.10.1 255.255.255.0
no shutdown
end
💡 Recuerda: ip address asigna la dirección IP y la máscara; no shutdown activa la interfaz.

🧩 Configuración completa del router

R1 
enable
configure terminal
interface FastEthernet0/0
ip address 192.168.10.1 255.255.255.0
no shutdown
end

2. Verificación del router

Después de configurar la interfaz, debemos comprobar que realmente quedó activa.

🔎 Comando principal

Cisco CLI 
show ip interface brief

Este comando muestra de forma resumida las interfaces, sus direcciones IP y su estado.

InterfaceIP-AddressMethodStatusProtocol
FastEthernet0/0192.168.10.1manualupup
✅ ¿Qué significa up/up? La interfaz está activa y el protocolo de línea también está funcionando correctamente.

3. VLAN administrativa en un switch

Ahora configuraremos la VLAN 99 como VLAN de administración del switch.

📋 Datos de la VLAN

DatoValor
VLAN administrativa99
NombreADMINISTRACION
IP del switch192.168.10.2
Máscara255.255.255.0
Gateway192.168.10.1
1

Crear la VLAN 99

S1 
enable
configure terminal
vlan 99
name ADMINISTRACION
exit
2

Configurar la SVI

La SVI corresponde a interface vlan 99.

S1 
interface vlan 99
ip address 192.168.10.2 255.255.255.0
no shutdown
⚠️ No confundas: interface FastEthernet0/1 es un puerto físico; interface vlan 99 es la interfaz virtual utilizada para administrar el switch.

4. Configuración del gateway

El gateway indica al switch qué dispositivo debe utilizar como puerta de enlace para comunicarse con otras redes.

🌐 Gateway del ejemplo

Como el router tiene la dirección 192.168.10.1, esa será la puerta de enlace del switch.

S1 
ip default-gateway 192.168.10.1
🧠 Para memorizar: el gateway del switch apunta al router. En este ejercicio, .1 = router y .2 = switch.

5. Asignar un puerto a la VLAN

La VLAN administrativa necesita que al menos un puerto del switch esté asociado a ella para tener conectividad.

🔌 FastEthernet0/1 → VLAN 99

En el ejemplo, el router está conectado al puerto FastEthernet0/1 del switch.

S1 
interface FastEthernet0/1
switchport mode access
switchport access vlan 99
no shutdown
✅ Resultado: el puerto FastEthernet0/1 queda asociado a la VLAN 99.

7. Comprobación de conectividad

Una vez configurados los dispositivos, comprobamos que pueden comunicarse entre sí.

R1

Desde el router

Haz ping hacia la IP de administración del switch:

PING 
ping 192.168.10.2
S1

Desde el switch

Haz ping hacia la dirección del router:

PING 
ping 192.168.10.1

8. Router vs. Switch

La diferencia más importante de esta práctica está en dónde se configura la dirección IP.

Característica Router Switch de capa 2
IP de administración/configuración Interfaz física Interfaz virtual de VLAN (SVI)
Ejemplo de interfaz interface fa0/0 interface vlan 99
IP del ejemplo 192.168.10.1 192.168.10.2
Gateway No se configura como en el switch ip default-gateway 192.168.10.1
⭐ Regla de oro:
Router → IP → interfaz física
Switch de capa 2 → IP de administración → SVI/VLAN
Gateway del switch → IP del router

🧠 Repaso rápido

Si puedes responder estas preguntas sin mirar las respuestas, ya tienes una buena base para la práctica.

¿Qué hace enable?

Permite entrar al modo privilegiado.

¿Para qué sirve no shutdown?

Activa una interfaz que puede encontrarse administrativamente apagada.

¿Qué es una SVI?

Una Switch Virtual Interface asociada a una VLAN.

¿Qué VLAN usamos?

La VLAN 99, con nombre ADMINISTRACION.

¿Cuál es la IP del router?

192.168.10.1

¿Cuál es la IP del switch?

192.168.10.2

¿Qué comando verifica interfaces?

show ip interface brief

¿Qué comando prueba conectividad?

ping seguido de la IP de destino.

¿Qué significa up/up?

La interfaz y el protocolo de línea están funcionando correctamente.
